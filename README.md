# Big Data Modeling

## Overview
This repository focuses on applying Python-based big data modeling techniques to process, filter, and analyze large datasets. 

## Key Features & Capabilities
* **Data Partitioning:** Segmenting large-scale datasets to optimize processing performance and resource management.
* **MapReduce Workflows:** Executing Map and Reduce operations using custom, pre-determined keys to efficiently clean and filter raw data.
* **Predictive Analytics *(In Progress)*:** Applying statistical and machine learning models to the processed target ($Y$) dataset for predictive analysis.

## Tech Stack
* **Language:** Python, PySpark, SQL
* **Core Concepts:** Data Partitioning, MapReduce, Key-Value Transformation, Predictive Modeling
